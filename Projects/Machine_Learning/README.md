# Machine Learning Projects

This folder contains supervised and unsupervised machine learning projects completed during Thinkful Data Science training.

## Featured work

### Stack Overflow Salary Analysis
Analyzes Stack Overflow survey data to explore relationships between compensation, education, professional experience, and lifestyle variables. The workflow includes data cleaning, salary normalization, outlier handling, visualization, and statistical hypothesis testing.

[Open the notebook](Supervised_Learning_Projects/Stackoverflow_users_salary_prediction.ipynb)

### Zillow Zestimate Kaggle Project
Applies supervised machine learning methods to Zillow housing data in a predictive modeling setting.

[Open the notebook](Supervised_Learning_Projects/Zillow_Kaggle_Zestimate_Competition.ipynb)

### News NLP Topic Summarization
Builds an NLP preprocessing workflow for news text using regular expressions, NLTK, spaCy, and scikit-learn tools.

[Open the notebook](Unsupervised_Learning_Projects/NLP_topic_summarization_from_news_data.ipynb)

## Historical note

These notebooks were originally completed in 2019. Some package syntax and local file paths reflect the original development environment. The analytical work is preserved while documentation is being improved for portfolio presentation.
