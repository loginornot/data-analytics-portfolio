# Data Analysis Projects

This folder contains business-oriented analytical work completed during Thinkful Data Science training.

## Iowa Liquor Sales A/B Test Proposal

This project analyzes Iowa liquor transaction data with a focus on sales performance and profitability. It develops a hypothesis that weaker-performing products may contribute to depressed profit and proposes a promotional experiment to test whether targeted promotions could improve results.

### Methods demonstrated

- Data loading and inspection with Pandas
- Data cleaning and transformation
- Exploratory analysis of sales and profit-related variables
- Data visualization with Matplotlib and Seaborn
- Business hypothesis development
- A/B testing and experiment-design thinking

[Open the notebook](Iowa_Liquor_Store_AB_Test_Proposal.ipynb)
